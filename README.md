# WeightEasy Landing Page

Next.js 14 (App Router) + Framer Motion animations.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy to Vercel
1. Push this folder to a GitHub repo
2. Go to vercel.com → Add New Project → Import the repo
3. Vercel auto-detects Next.js. Click Deploy.

## Structure
- `app/` — App Router pages, layout, global CSS
- `components/` — landing-page sections (Hero, Truths, Help, Stories, Manifesto, Download, Footer, Nav)
- `components/phones/` — animated phone mocks
- `public/` — static assets (logo, fonts)
